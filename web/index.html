What I'd do next

Small steps that fit into the page build Airial already runs.

1 · Before publishRun vet_post as a gate

Call it when a card is attached to a page. DROP sends the card to a review queue instead of the live page, so the Greenland and Jaipur cases never ship.

2 · Borderline casesSmall LLM judge for "area" and flagged cards

The keyword rule was right on 8 of 23 off_topic flags. A cheap judge on only the flagged and town-level cards would cut the false hits without judging all cards.

3 · Measure recallHand-label a random set of kept cards

I only checked flagged cards, so misses are unknown. A labelled sample of kept cards gives a real miss rate to track each week.
